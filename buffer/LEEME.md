# Buffer

Aquí aterriza lo que **todavía no sabemos dónde va**: una idea suelta, una página de libreta
transcrita, algo que dijo el club, un enlace, una nota de madrugada.

Reglas:

- Un archivo por cosa: `AAAA-MM-DD-<slug>.md`.
- **Se vacía al cerrar cada sesión**: cada nota se promueve a su destino definitivo según la tabla de
  routing de `CLAUDE.md`.
- Si algo lleva **más de una semana** aquí, hay que preguntar qué se hace con ello. Un buffer que se
  llena es un buffer que no se usa.

Este archivo (`LEEME.md`) no se borra; todo lo demás es temporal.
